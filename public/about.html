Behind the App


An exploration into the world of Generative AI.

Welcome to Chat G-Az! This application is a project by Giftirul Aziz, designed to demonstrate a clean, functional, and responsive chat interface powered by Google's powerful Generative AI models.

Core Technologies:

  • Backend: Built with Node.js and Express for a fast and reliable server.
  • AI Integration: Connected to the Google Gemini API to provide intelligent and contextual responses.
  • Frontend: Crafted with pure HTML, CSS, and JavaScript for a lightweight and snappy user experience.

The goal is to showcase a practical implementation of modern AI capabilities in a user-friendly package. Feel free to explore the code, ask the AI anything, and see how it all comes together.
